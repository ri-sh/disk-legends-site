Disk Legends — Support

Disk Legends is a macOS app for finding and clearing up disk space — duplicate files, old and unused files, and common space hogs like Xcode build data and device backups, all shown in a live visual treemap.

Need help?

Email rishabhsixfeet@gmail.com with a description of the issue and, if possible, your macOS version.

Frequently asked

Does Disk Legends send my files anywhere?
No. Disk Legends never makes a network request and only reads files you explicitly grant it access to. See the Privacy Policy.

Why does it ask for permission to a folder?
macOS sandboxes apps by default — Disk Legends can only read a folder after you grant access via the system file picker, which is standard for this kind of Mac app.
